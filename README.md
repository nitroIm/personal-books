# 📚 Personal Books

Репозиторий для личных книг и аудиокниг.

**Что делает:**
- 🔍 Ищет книги по теме (arXiv, Zenodo, Semantic Scholar)
- 📥 Скачивает PDF
- 🎧 Превращает PDF в аудиокнигу (MP3)
- 📤 Отправляет MP3 в Telegram

**Просто и без лишнего.**

---

## 🎯 Как работает

```
/find тема      → 5 карточек книг
[✅ Скачать]    → PDF в репо
[🎧 Аудио]      → MP3 в Telegram
```

PDF остаётся в репо, MP3 удаляется после отправки.

## 🤖 Команды бота

### 🔍 Поиск

```
/find <тема>

Пример: /find Schopenhauer
```

**Что приходит:**
- 5 карточек по одной
- Название, источник, описание
- Кнопки: **[✅ Скачать] [❌ Отклонить]**
- Внизу: **[Показать ещё N]**

### 📥 Скачивание

Тапни **[✅ Скачать]** → PDF качается в `personal_books/` → приходит «Готово».

### 🎧 Аудио

```
/audio             → список книг
/audio <имя>       → MP3 (RU)
/audio <имя> --en  → MP3 из EN оригинала
```

**Что приходит:**
- MP3 по частям (по 45 минут)
- Одна книга = 3-6 частей
- mp3 удаляются после отправки

---

## 📊 Лимиты

| Что | Значение |
|---|---|
| PDF | до 100 МБ |
| MP3 | до 50 МБ |
| Частей на книгу | без лимита |

Длинные книги → 4-6 частей MP3.

---

## 🎧 Аудио — детали

- gTTS, русский голос
- ~1 МБ/минута
- 45 минут = одна часть
- Сканы PDF пока не поддерживаются

---

## 🛠 Частые проблемы

| Проблема | Решение |
|---|---|
| PDF > 100 МБ | Качай вручную |
| MP3 упал | Проверь Actions log |
| Скан не читается | Нужен текстовый PDF |
| Actions не запускаются | Billing → spending limit ≥ $5 |

---

## 📌 Правила

1. Только личное использование
2. PDF хранятся в репо
3. MP3 удаляются автоматически
4. Не коммитим временные файлы
